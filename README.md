# Автодом — демо сайта

Демонстрационная версия v6 для согласования дизайна. Ремонт и обслуживание автомобилей: Витебск, ул. П. Бровки, 4Б.

Форма демонстрационная: заявки не отправляются и данные не сохраняются. Для реальной записи доступны телефонные ссылки.

## Запуск локально

`python -m http.server 8776 --bind 127.0.0.1`

Открой http://127.0.0.1:8776/ . Файлы сайта лежат в корне; сборка не требуется.

Исходные сведения и фотографии: https://autodomvitebsk.by/ . Эмблемы марок: https://github.com/filippofilip95/car-logos-dataset . Материалы сохраняют права их владельцев.
